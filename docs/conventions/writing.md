# Writing

1. Write the skill files and `README.md` in English.\
   [agent-instructions.md](agent-instructions.md) gives the language of the agent instructions.
2. Write the skill files, `README.md`, and the agent instructions in ASD-STE100 (Simplified Technical English).
3. Write the requirement levels with the BCP 14 keywords in upper case (RFC 2119, RFC 8174): MUST, MUST NOT, SHOULD, SHOULD NOT, and MAY.
4. Use Semantic Line Breaks, and make the breaks show in the rendered output.\
   End each broken line with a `\`.\
   Do not put a `\` at the end of the last line of a paragraph or a list item.
