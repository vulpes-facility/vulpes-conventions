# Icons and images

1. Use one icon set: the set of the base design system, or the icons of the platform.\
   Examples are SF Symbols, Material Symbols, Fluent System Icons, and the Adwaita symbolic icons.
2. Use the sizes of the icon set, and give each icon one meaning in the whole product.
3. Give each button with only an icon an accessible name, and a tooltip on a platform with a pointer.
4. In a right-to-left language, mirror the icons that show a direction or an order.\
   Do not mirror check marks, media controls, clocks, or icons of real objects.
5. Do not put text in images, except in logos.
6. Give each image a fixed aspect ratio, and a size for each pixel density or a vector form.
7. Make the app icon by the specs of each platform: the shape, the sizes, the safe zone, and the dark and tinted variants.\
   On the web, also give a favicon and a maskable icon.
