# Input

Design for the input capabilities that the device has, not for the name of the device.\
A tablet can have a keyboard and a trackpad, and a laptop can have a touch screen.

1. The input can change while the app runs.\
   Do not select one input method at the start.
2. Use hover only to show more.\
   Do not put information or a function only in a hover state, because touch has no hover.
3. Give each item with actions a context menu that opens with a right-click and with a long press.
4. Show the keyboard shortcuts of the commands in the menus and the tooltips.\
   Use the modifier of the platform, and do not give a shortcut of the system or the browser a different function.
5. Use the touch target size of the platform whenever touch is available (`SKILL.md`, section 4).\
   With only a precise pointer, controls MAY use the compact sizes of the platform.
6. Give each gesture a control that does the same action with one tap.\
   This applies to swipes, pinches, drags, and gestures with more than one finger.
7. In compact windows, put frequent actions where the thumb reaches them.
