# Principles

1. The principles in `docs/conventions/design.md` of the project have priority over this file.
2. Less, but better (Dieter Rams) is the first principle of this skill (`SKILL.md`, section 2).\
   Remove what does not help a main task, then make what remains better.
3. Review a design with the ten usability heuristics of Jakob Nielsen.\
   Name the heuristic in each finding.
4. When no rule decides a case, use an established principle, and name it.\
   Examples are the Gestalt principles, Fitts's law, Hick's law, and the interaction principles of Don Norman.
